Vita Distribuidora

Site institucional e sistema de pedidos online para a **Vita Distribuidora**, na região de Brasília/DF.

Funcionalidades
* **Catálogo de Produtos:** Visualização clara de fardos.
* **Pedido Direto via WhatsApp:** Formulário interativo que monta a mensagem com os dados do cliente e abre o chat instantaneamente.
* **Botão Flutuante:** Atalho rápido para contato fixado no canto da tela.
* **Layout Responsivo:** Adaptado para celulares, tablets e computadores.

Tecnologias Utilizadas
* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização personalizada e design moderno)
* **JavaScript** (Manipulação do DOM e integração com a API do WhatsApp)
